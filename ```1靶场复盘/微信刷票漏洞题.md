# 一道关于微信刷票漏洞的题
### 背景：小墨在微信群里面收到一个关于“家乡美”最美乡村评选微信投票，小墨想让自己的家乡成为第一名
#### 核心考点：
1. User-Agent伪造（模拟微信浏览器）
2. X-Forwarded-For IP伪造（绕过单ip投票限制，用多ip进行刷票）
3. Burp Intruder多变量爆破刷票
#### 微信 User‑Agent（Android）
```http
Mozilla/5.0 (Linux; Android 13; xxx) AppleWebKit/537.36 (KHTML, like Gecko) Version/4.0 Chrome/114.0.5735.130 Mobile Safari/537.36 MicroMessenger/8.0.49.2620(0x28003133) NetType/WIFI Language/zh_CN
```
#### XFF伪造IP头
```http
X-Forwarded-For: 112.28.111.100
```
变量Payload在倒数第二段和最后一段（保证票数可以到第一），范围在1-254，IP每段只能0-255，到255就返回-1（错误）。
#### 成功标准
必须看响应内容，如果
`"errorcode"=0`→投票成功；
`=-1`→失败
#### 同类拓展头
```http 
X-Forwarded-For: 127.0.0.1
X-Real-IP: 127.0.0.1
Client-IP: 127.0.0.1
```
